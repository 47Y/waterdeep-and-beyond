# Silvered Warhammers

[[Steam and Steel]] created a decorative silvered warhammer from one silver bar for use as a [[Vault Keys|Vault key]]. It was completed quickly because it did not need to function as a weapon.

[[Dick Mixon]] later supplied two additional silver bars and commissioned a functional silvered warhammer, allowing the smiths to keep the excess silver. It was expected to be ready within a few days.
