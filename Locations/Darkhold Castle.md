# Darkhold Castle

Under Speak with Dead, [[Bashekk Ortallis]] named Darkhold Castle as the main [[Zhentarim]] hideout. [[Wern Malkrave]] instead said the main hideout was in the sewers.

A guard questioned by [[Cordan]] did not recognize the name Darkhold Castle.
