# Drunk Track

Shared drinking rules for tavern games. Each drinking game embeds this section, so a change here updates every game. (King of the Drunks keeps its own copy of the track.)

## Rules

### Taking a drink

Whenever a game says **drink**, the drinker makes a **Constitution saving throw**. The DC is **10** unless the game sets its own.
- **Total equals or beats the DC:** nothing happens.
- **Total is below the DC:** gain **1 failure** on the Drunk Track.
- **Natural 1** (the d20 shows a 1): gain **2 failures**.

**Alcohol counts as poison.** Traits that give advantage on saves against poison, such as **Dwarven Resilience**, give advantage on these saves. Resistance to poison *damage* doesn't help.

### The track

| Failures | State | Effect |
|---|---|---|
| 0 | Sober | None |
| 1 | Tipsy | None. Roleplay only. |
| 2 | Drunk | **Poisoned**: disadvantage on attack rolls and **ability checks**. (Saving throws are not affected.) |
| 3 | Out | Can't take part in any more drinking games tonight. Stays poisoned until a long rest. |

- **The track carries over** from game to game through the night. 
  - A long rest clears it.
  - A short rest clears one failure point.
- **Drunk matters in skill games.** A Drunk player has disadvantage on every ability check, so a few drinks early can lose a darts match later.
- **Immune to the poisoned condition?** You still mark failures and still drop **Out** at 3, but you ignore the poisoned effect at Drunk.
